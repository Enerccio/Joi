# Joi

Joi is a self-hosted personal AI assistant. A Java server is her brain (the conversation, memory, moods, bodies, events and
tools), and a node on each of your machines is where she can be seen, heard and useful: it shows her avatar, listens, and
offers the machine's tools to her.

!!!warning This manual is being written
The pages are stubs: each lists what it will cover. The text comes page by page.
!!!

## What it does

- **Assistants** with their own persona, personality, memory and moods. See [Assistants](user/jois/index.md).
- **Bodies** - 3D models converted to VRM, outfits and animations. See [Bodies](user/bodies/index.md) and
  [Animations](user/animations/index.md).
- **Server tools** with a permission chain, such as web search. See [Server tools](user/tools/index.md).
- **Nodes** - the JavaFX node, the terminal node and the Looking Glass. See [Nodes](user/node/index.md).
- **An open API** for your own nodes and scripts. See [The protocol](developer/protocol.md).
